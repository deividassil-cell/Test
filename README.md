# Šeimos finansai

Android UI prototipas pagal Furniplan įkvėptą tamsią pilkai žalsvą stilistiką.

Ekranai:
- Pradžia
- Mokėjimai
- Kalendorius
- Fondai
- Sutartys

Tai pirmas UI prototipas su demo duomenimis.

Codemagic:
repo šaknyje yra `codemagic.yaml`. Paleidus `android-debug`, turėtų būti sugeneruotas `app-debug.apk`.
